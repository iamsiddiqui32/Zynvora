# 🎬 Zynvora

> **Stream Beyond Imagination.**

Zynvora is a modern, responsive streaming web application designed to provide a clean and immersive experience for discovering and watching animated movies.

---

## ✨ Features

* 🎥 Modern movie streaming interface
* 🔎 Fast movie search
* 🏷️ Movie categories and genres
* ⭐ Movie ratings and information
* ❤️ Favorites system with local storage
* ▶️ Integrated video playback
* 📱 Responsive design for mobile, tablet, and desktop
* 🎞️ Featured movie sections
* 🌙 Premium dark-themed interface
* ⚡ Smooth animations and transitions
* 🚀 Fast and modern web experience

---

## 🛠️ Tech Stack

* **React**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **TanStack Router**
* **Framer Motion**
* **Vercel**

---

## 🎨 Design

Zynvora focuses on a cinematic streaming experience with a modern dark interface, smooth animations, responsive layouts, and an easy-to-use navigation system.

## 💻 Getting Started

### Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### Navigate to the project

```bash
cd YOUR_REPOSITORY_NAME
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The development server will then be available locally.
